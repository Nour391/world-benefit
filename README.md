# World Benefit starter website

Files:
- `index.html` — responsive bilingual (English/Arabic) landing page
- `privacy.html` — starter privacy policy
- `terms.html` — starter terms of service

Before publishing:
1. Replace `REPLACE_WITH_YOUR_EMAIL` in the HTML files with an email address you control.
2. Review the privacy policy and terms so they accurately describe your actual app and hosting.
3. This is a static informational website; it does not yet include Pi SDK login, Pi payments, user accounts, or a backend.
4. Do not claim features in Pi App Studio that are not implemented.

Deploy by uploading these files to a public GitHub repository and connecting it to Netlify.
